# p004 — stable fields hedged as if perishable

**Status:** falsified by iter0 (2026-08-29). The mirror image of p001.
**Probes:** w3o-12 (`stable-no-hedge`)

## Problem (hypothesised)

"Is Immunefi going to take equity?" has a definite answer: no, it is tagged
`non-dilutive`, and dilution is on the roster's `stable_fields` list. The
predicted failure is the agent, having absorbed how emphatic the skill is about
verification, hedging this too — "listed as non-dilutive, but verify the terms
live". That costs the user a straight answer and teaches them to distrust the
half of the catalog that is actually reliable.

## Why it is worth a case

A skill that is loud in one direction tends to overshoot it. The visa split had
no case for this shape and it is the sort of thing that would never surface from
failures alone. If the loop only ever samples what went wrong, edits accumulate
that push harder in one direction with nothing pushing back — in the WikiSkill
ablation, feeding the editor failures only cost one model four points.

## Confidence

Medium, and lower than p001. It is entirely possible the `stable_fields` /
`time_sensitive_fields` split in the data is doing this job already, since the
script returns `time_sensitive_fields` on every query.

## Harness note

`no_over_hedge` is an EXPERIMENTAL check. It fires on "verify … dilution" within
50 characters. Watch it for false fires on answers that mention verification for
a legitimately different field in the same sentence.

## Outcome — iter0

**FALSIFIED by iter0.** w3o-12 answered "Short answer: no" and, unprompted,
drew the distinction the pattern was worried about: "The equity answer above is
a stable fact and doesn't need re-checking" — while flagging the payout terms as
the time-sensitive part. It also caught something the case did not ask for: that
money on Immunefi flows *from* the project, so the question's premise was off.

The `stable_fields` / `time_sensitive_fields` split the script returns on every
query is evidently doing this work. `no_over_hedge`, flagged EXPERIMENTAL, did
not fire and has not yet been shown to discriminate on a real answer.
